# buildup_learning

Booking list와 예비 플랜(팔레트별 배정)을 받아서, 각 팔레트에 배정된 화물이
실제로 들어가는지(높이 160 컨투어, 팔레트 사이즈, 총중량) 검사하고,
안 들어가면 어디까지 들어가고 무엇이 넘치는지 보여주는 도구.

이후 단계로 배치 순서와 적재 위치를 제안하는 모델(3D bin packing + RL)을 붙인다.

## 입력
- `booking.csv` : AWB, 개수, 치수(L/W/H cm), 개당 중량, SHC
- `plan.csv`    : ULD 번호, 타입(PMC/PAG/...), 배정 AWB 목록

## 출력
- 팔레트별 판정: OK / 넘침(초과 부피·개수·중량) / 위험(용적률 90% 이상)
- 넘치는 경우 대안 제안(다른 팔레트로 이동, 추가 팔레트)

## 구조
```
src/buildup/   환경(높이맵, 컨투어, 적재 규칙), 휴리스틱 패커, 판정기
data/          팔레트·컨투어 정의(JSON), 합성 샘플
tests/
notebooks/     학습·실험용
```

모든 샘플 데이터는 합성 데이터이며, 실제 업무 데이터는 저장소에 넣지 않는다.
